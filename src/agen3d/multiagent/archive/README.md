# Archived controllers

This directory contains the V1–V3 policies and raw-input pipeline, the AHA Next and Diagnosed variants, and their supporting tools. Existing Python launch commands continue to resolve through the multiagent package.

The original [multiagent guide](guides/multiagent.md), [AHA-auto notes](guides/aha-auto.md), and [AHA-driven notes](guides/aha-driven.md) are retained here. Use the [room reconstruction guide](../README.md) for current commands.
